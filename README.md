Simple Password Validator

Description

A Python program that checks whether a password meets basic security requirements.

Requirements

- Minimum 8 characters
- One uppercase letter
- One lowercase letter
- One number
- One special character

Tools Used

- Python
- String module

How to Run

1. Open the project in VS Code.
2. Run "password_validator.py".
3. Enter a password to check its validity.

Output

Displays whether the password is valid and lists any missing requirements.

Concepts Used

Strings, loops, conditions, and the string module.
